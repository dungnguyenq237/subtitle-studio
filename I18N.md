# Internationalization

38 distinct language/variety entries follow the Ethnologue 2026 section of the user-supplied Wikipedia list. The order and representative flags are in assets/languages.js. Flags are representative regional symbols, not exclusive mappings between countries and languages.

## Runtime

The native select uses each language's native name. Catalogs contain 445 entries and are fetched lazily from the same origin. No user input is sent to a translation service. The English HTML remains crawlable and canonical; this release does not claim separately indexed localized SEO landing pages.

URL ?lang= takes precedence over the locally stored language preference. Invalid codes resolve to English; failed/incomplete catalogs fall back to English with a status notice. Storage errors do not block the tool. RTL is explicit for the Arabic varieties, Urdu, Western Punjabi and Persian. Code/timestamps and puzzle grids keep LTR layout.

User input, subtitle exports, custom card titles and puzzle words are protected from translation. Generated instructions and errors are translated; cloneLocalized preserves their source metadata when previews are cloned from print sheets. Switching language does not regenerate cards or invalidate subtitle output. Language preference is the only value this feature saves to localStorage.

## Catalog maintenance

All catalogs are AI-generated drafts, not native-editor-reviewed translations. They include distinct written varieties rather than silently aliasing Cantonese/Wu to Mandarin or Arabic varieties to MSA. Native review is especially valuable for regional varieties. Preserve named interpolation tokens and brands/format syntax. The Node tests reject missing keys, empty values or changed placeholders. Technical examples and user data intentionally remain literal.

## Validation

Run npm ci and npm test for unit tests. Subtitle Studio passed 50 tests and Party Paper passed 49 tests during implementation. The CUA Chromium preview report in e2e/preview-results.json records 646 workspace/content/mobile combinations plus functional regression flows. At 320px and 390px, all 38 locales were checked for horizontal overflow. It also records real VTT download, fallback/race checks, keyboard navigation, stored preference, translated errors, cloned preview labels and protected user content. Real print CSS was checked with RTL sheets; the native Print/PDF dialog did not open in that environment, so that dialog's PDF output was not verified there.

## Repeatable browser suite

Install the browser with npx playwright install --with-deps chromium, then run npm run test:e2e. playwright.config.mjs starts a local static server; E2E_BASE_URL can target another already-running environment. e2e/runner.mjs shares the locale/content/functional assertions with the executed CUA checks, and e2e/playwright.spec.mjs supplies a normal Playwright adapter plus storage/network failure and download/PDF tests. The GitHub workflow runs unit and browser checks and retains failure traces/reports. Browser coverage is Chromium; Safari/Firefox and native linguistic review are not claimed.
