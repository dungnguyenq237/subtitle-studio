Subtitle Studio field guide

Fix subtitle timing. Convert SRT and VTT.

Use this workflow when you already have a subtitle file and need to adjust its timing or change its format. Keep a copy of your original file before editing.

1. Load your captions

Open the workspace and choose a UTF-8 .srt or .vtt file up to 2 MB, paste subtitle text, or select “Load sample” to try it. Each cue needs a start time, an end time and caption text.

2. Find the timing offset

If captions appear two seconds after the dialogue, enter −2 seconds to move them earlier. If they appear half a second too soon, enter 0.5 to delay them. Use 0 when you only want to convert the format.

Original: 00:00:04,000 → 00:00:06,000
Offset:   −2 seconds
Result:   00:00:02,000 → 00:00:04,000

A single offset corrects a consistent delay. If the timing drifts progressively during the video, this tool does not perform the time stretching or frame-rate correction needed to fix it.

3. Choose SRT or WebVTT

SRT is commonly used in editing and caption workflows. WebVTT is used for browser video text tracks. Select the format your player or editor accepts, then press “Process subtitles.” Exporting VTT adds the WEBVTT header and uses dots for milliseconds.

4. Review and download

Read the output and quality notes. An overlap or long-line warning is a prompt to review the captions, not a guarantee that they are unusable. Negative start times are rejected: choose a smaller negative offset if the first cue would start before zero.

After changing the source, offset or format, process again before downloading. The previous output is marked as stale. Check the beginning, middle and end in your video player after export.

Common questions

Does my file leave my device?

No. Subtitle processing runs locally in your browser. Downloaded output is saved by your browser.

Does it preserve every WebVTT feature?

No. Cue positioning metadata is omitted. This tool focuses on text and timing; keep the original file if you need its layout or styling information.

Why is my file rejected?

Check that it is UTF-8 SRT or VTT with valid timestamps, that each end time follows its start time, and that it is within the 2 MB limit.
